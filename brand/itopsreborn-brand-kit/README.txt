TYPE
  Wordmark lettering is outlined (no font needed to open files).
  Drawn in Inter Display (Bold + Light/Regular); taglines in a monospace face.
  On the web, your existing system font stack ("Segoe UI", -apple-system, sans-serif)
  matches closely. Inter is free on Google Fonts if you want an exact match.

WEBSITE SNIPPET (put the 02-icon files in your site root)
  <link rel="icon" href="/favicon.ico" sizes="any">
  <link rel="icon" href="/favicon.svg" type="image/svg+xml">
  <link rel="apple-touch-icon" href="/apple-touch-icon-180.png">
  <meta property="og:image" content="https://itopsreborn.com/link-preview-og-1200x630.png">

USAGE
  - Leave clear space around the logo at least half the height of the mark.
  - Don't stretch, recolor outside the palette, rotate, or add effects.
  - Minimum size: horizontal logo 140 px wide; mark alone 24 px (use favicon files below that).
